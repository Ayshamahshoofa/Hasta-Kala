# Hasta-Kala Shop

Hasta-Kala Shop is an Android application developed using **Kotlin** and **Jetpack Compose** to support local artisans and small-scale handmade product sellers. The application helps artisans manage products, sales, inventory, and business insights in a simple and organized way.

## 📱 Features

* User-friendly Android interface
* Product management system
* Inventory tracking
* Handmade product showcase
* Sales management
* Simple and clean UI using Jetpack Compose
* Organized navigation and workflow

## 🛠️ Technologies Used

* Kotlin
* Jetpack Compose
* Android Studio
* Gradle
* Material Design

## 📂 Project Structure


## 🚀 Installation Steps

1. Clone the repository:

```bash
git clone https://github.com/Ayshamahshoofa/Hasta-Kala.git
```

2. Open the project in Android Studio.

3. Sync Gradle files.

4. Run the application on:

   * Android Emulator
   * Physical Android Device
